# 服化道设计技能

[技能说明]
    美术设计技能，将导演提供的人物清单、场景清单和道具清单转化为可直接用于文生图工具生成参考图的详细提示词。

    人物提示词出图格式：一张图，左侧面部特写，中间竖椭圆形人相框一张特写，右侧全身正面/侧面/背面设定图，白色背景。
    场景提示词出图格式：每个场景一张图，独立条目。
    道具提示词出图格式：每个道具一张图，纯道具静物展示，白色背景。

[执行流程]

    第一步：读取上游产物
        - 读取导演分析产出中的人物清单、场景清单和道具清单
        - 读取 gemini-image-prompt-guide.md 了解提示词写法规范
        - 读取 examples/ 下的示例文件，了解高质量提示词的写法标准
        - 参考「已有素材库」章节中的角色清单、场景清单和道具清单，了解已有的资产设计
        - 根据人物清单、场景清单和道具清单中的"素材状态"列，只为标注为"新增"或"变体"的项设计提示词
        - 标注为"复用"的项跳过，使用已有素材库中的提示词，不重新设计

    第二步：设计人物造型提示词
        为每个人物编写设定提示词：

        出图布局：
        - 一张图，左侧面部特写，中间竖椭圆形人相框一张特写，右侧全身正面/侧面/背面三视图设定图
        - 白色干净背景
        - 角色设定图风格

        提示词必须包含：
        - 角色整体定位（年龄、性别、种族/人种——如黄种人/白种人/黑种人/亚洲人/欧洲人，必须明确写出）
        - 面部细节：脸型、五官、肤色、发型/发色、表情
        - 体型：身高、体态
        - 服装：款式、颜色、材质、细节
        - 配饰：手表、耳环、眼镜、包等（角色固有的穿戴配饰）
        - 鞋子
        - 整体气质

        【角色纯净原则】此提示词只描述角色本身。角色持有的兵器、法杖、信物等道具
        由独立道具设计步骤处理，不得出现在角色提示词中。

    第三步：设计场景环境提示词
        为导演分析出的每个场景独立编写提示词，格式与人物提示词一致：

        每个场景一个独立条目，格式：
        ## 场景名（epXX）

        **提示词**：
        [完整场景描述提示词]

        提示词必须包含：
        - 地点类型与空间布局
        - 时间（影响光照）
        - 光源类型与光线方向
        - 整体色调/色彩倾向
        - 关键道具/家具/物件
        - 空间纵深与层次
        - 氛围/情绪
        - 风格：必须与 ## 项目配置 中的「视觉风格」（如真人写实/3D CG/国漫/日漫等）保持一致，在提示词中明确体现该风格的特征

    第四步：设计道具提示词
        为导演分析出的每个关键道具编写设定提示词：

        出图布局：
        - 一张图，纯道具静物展示
        - 白色干净背景
        - 道具独立陈列，无人持有，无人物入镜
        - 道具占画面主体 70% 以上

        提示词必须包含：
        - 道具类型定位（兵器/饰品/器物/信物等）
        - 材质：金属/玉石/木/布/纸等，须明确
        - 颜色/光泽
        - 形状与结构细节
        - 工艺/装饰特征
        - 整体风格（与项目视觉风格一致）

    第五步：输出
        按照 templates/art-design-template.md 定义的输出格式，以 XML 标签形式输出。
        人物提示词用 <characterPrompts> 容器包裹，场景提示词用 <scenePrompts> 容器包裹，道具提示词用 <propPrompts> 容器包裹。
        type 属性标记状态：新增/复用/变体

[提示词写法原则]
    参考 gemini-image-prompt-guide.md，核心要点：

    - 叙事描述式：用完整段落描述，不要关键词堆叠
    - 具体化：所有描述必须具体到可视化的程度
        - "穿红色衣服" ✗ → "穿深红色修身棉袄外套，内搭碎花棉布衫" ✓
        - "室内场景" ✗ → "现代都市写字楼的开放式办公区，大部分工位已空" ✓
    - 摄影术语融入自然语言
    - 情绪通过视觉细节传达，不要抽象描述

[注意事项]
    - gemini-image-prompt-guide.md 是提示词写法的核心参考
    - 【角色版式·逐字固定】角色提示词的开头必须是这一句，一字不改、不增不减：
      「角色设定图，白色干净背景。画面左侧是面部特写，中间是竖椭圆形人相框内的人物特写，右侧是全身正面、侧面和背面三个角度的设定图，水平排列。」
      仅此三格（左特写 / 中竖椭圆相框 / 右三视图），**纯白背景**；
      画面中**不得**出现任何其它图块——不加额外局部细节图、表情小图、动作示意、色卡、文字标签或装饰元素。
    - 场景提示词要包含足够的环境细节以确保场景可信度和一致性
    - 所有提示词必须体现 ## 项目配置 中的「视觉风格」——如为"3D CG"则提示词应包含3D渲染术语和光影特征，如为"国漫"则应有国漫线条和色彩特征
    - 「目标媒介」（电影/短剧/漫剧/MV/广告）只影响**成片**的节奏与分镜构图，**不影响资产图**——资产图不按竖屏/横屏媒介调整比例
    - 【画面比例】所有资产图（角色/场景/道具）一律 **16:9 横构图**，与 ## 项目配置 里的画面比例无关（那是**成片**比例）。
      无论项目画面比例是 16:9 还是 9:16，资产图都按 16:9 出图，横向上留出空间
    - 如果是为变体设计（如同一人物的冬装版），需在提示词中注明与原版的关联和差异

    【重要】每个角色、场景和道具的提示词是完全独立的图片生成任务，互不依赖。因此：
        - ❌ 禁止引用其他角色/场景/道具的提示词（如"面容与XX相似"、"材质同XX"）
        - ✅ 每个提示词必须独立包含该角色/场景/道具的完整视觉描述
        - ✅ 道具提示词必须独立描述材质、形状、颜色等全部细节
        - 审稿人无法通过查阅其他提示词来补全信息，因为每张图片是单独生成的

    【硬性要求】提示词必须以「{visualStyle}风格，画面比例16:9」开头。
    画面比例**固定写 16:9**，严禁写成 ## 项目配置 里的其它值（如竖屏 9:16）——资产图永远是 16:9 横构图。
    例如 visualStyle 为"3D中国古风"时：
        正确："3D中国古风风格，画面比例16:9，年轻男性，长发束发，白色古装长衫..."
        错误（写成竖屏）："3D中国古风风格，画面比例9:16，年轻男性..."
        错误（缺少风格开头）："年轻男性，长发束发，白色古装长衫..."
    这条规则优先级高于所有其他规则，不得违反。

    【硬性要求·白底资产画布不透明】角色提示词与道具提示词**末尾必须原样追加**下面这一句
    （一字不改，不得改写、不得省略、不得用「白色背景」「干净背景」之类字样替代）：
        「输出为完整的16:9不透明画布，整张画布从边缘到边缘均填充纯白色（#FFFFFF）。背景必须是实心白色像素，不得透明、不得有 alpha 通道，不得出现棋盘格。」
    原因：文生图模型会把「白色干净背景」理解成抠图底，输出带 alpha 通道的透明图，显示为棋盘格。
    ⚠️ **仅角色与道具适用**。场景是完整环境呈现，**严禁**给场景提示词追加这一句。

【名称变体规则】
同一角色的名称主体（括号前部分）相同但后缀不同，视为"变体"而非"新增"。
例如：已有"夜（黑豹幼崽）"、当前"夜（黑豹）" → 主体名都是"夜" → 变体
输出时 name 用当前名称，type 属性设为"变体"。
道具的名称变体规则同上。
