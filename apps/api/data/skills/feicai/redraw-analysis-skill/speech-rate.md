# 各语言语速统计表

`redraw-analysis-skill` 的**唯一语速出处**。SKILL.md 与 localization-guide.md 都引用这里，
**不要另抄一份**——两处各写各的，迟早会漂。

---

## 怎么用

语速只有一个用途：**判断一段译文塞不塞得进给定的时长**。

**真正的硬约束永远是原片时长 `T`**（取自转写稿的起止差）。
这张表只是让你在动笔翻译之前，能先估一下「这句话用目标国语言要说多久」。
估算值和实测值有出入是正常的——**`T` 优先**。

## 中文那一行：只做体检，不做配额

转绘里台词时长来自转写稿的**实测时间戳**，不需要估。这一行只用来发现转写错误：

> 一句 20 字的中文台词，按 4 字/秒应该 ≈5 秒。
> 如果转写稿说它只花了 1 秒（= 20 字/秒），那多半是 ASR 出错了——
> **回去校订转写，不要拿错的时长去翻。**

上下浮动 30% 以内算正常（语速本来就随情绪走），超出就该回头看一眼。

## 校准

⚠ 除中文外的数字都是**经验值，未实测**。它们只影响「翻译时的心算」，
不影响正确性（正确性由 `T` 兜底）。但要精确，得按目标国的实际配音样本校准：

1. 取该语言一段真实配音音频
2. 数出词数（或 モーラ / 音节数），除以音频时长
3. 用结果替换表中数值

同一种语言的不同口音（如西班牙 vs 拉美）语速差异不大，表里不分开。
