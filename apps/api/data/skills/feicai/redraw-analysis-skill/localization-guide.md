# 目标国化指南

配套 redraw-analysis-skill 使用。三部分：命名、翻译配额、文化符号替换。

---

## 一、命名规则

**角色名**
- 换成目标国的常见姓名，名字 + 姓氏都要符合目标国习惯
  - 英语：Emily Chen、Daniel Wu、Sophia Bennett
  - 西语：Lucía Ramírez、Mateo Herrera
  - 葡语（巴）：Beatriz Almeida、Rafael Souza
  - 日语：藤原 結衣、佐々木 蓮
  - 韩语：서지우、강민준
- **保留命名关系**：同一家族共用姓氏；同辈 / 上下级 / 亲疏的称呼差别要在名与姓的选择上体现出来
- 中文特有称谓（师兄、师姐、王爷、娘娘、掌门、总裁）换为目标国文化中的**对等称谓**，
  而不是音译。找不到对等物的，保留剧情功能、改写为当地能理解的层级关系
  （例：仙门掌门 → 学院院长 / 商会会长）

**场景名**
- 地点直译，保留辨识度。不美化、不抽象化
  （例：「爱希斯沙龙」→ `Aether Salon`，不是 `The Dream Lounge`）

**道具名**
- 功能直译优先（青云令 → 一个令牌类信物，`Obsidian Sigil`）
- 中文独有文化符号换成目标国文化中的**对等物或意象化命名**，不音译
- 换名后提示词里的**形态描述要跟着改**：换成西方意象却还写着「青玉蟠龙纹」是自相矛盾

---

## 二、翻译配额

**核心：目标时长锚定原片时长，翻译反过来适配它。** 不是先翻译再看多长。

**配额算法**

```
T   = 该句台词在转写稿里的起止差（秒）      ← 硬约束，来自转写稿
上限 = T × 1.15                            ← 允许 +15% 弹性
下限 = T × 0.85
```

产出译文后自检：按目标国语速读一遍，落在 [下限, 上限] 内即合格。

**只有译文那句参与配额。** 台词列里括号中的中文回译是给人对照用的
（写法见 SKILL.md [输出格式]），它既不影响这几秒该说多少字，也不参与语速自检 ——
别为了给括号腾地方去压译文。

**目标国语速参考值**见 **speech-rate.md**（唯一出处，连中文的 4 字/秒也在那张表里）。
不要凭印象估语速，也不要在这里另抄一份表——两处会漂。

**配额溢出时的处理顺序**（严格按序，不得跳步）

1. **换更紧凑的等义表达** —— 换词、换句式，**信息量不变**
2. **用满 +15% 弹性** —— 允许配音略快，但不许快到失真
3. **延镜** —— 拉长该镜的生成时长（源片区间不变），见 SKILL.md [拆镜与延镜]
4. **拆镜** —— 延镜顶到 15 秒仍装不下时，把该镜劈成两镜，
   多拿一个生成单元来承载译文。拆点与收口规则**全部**在 SKILL.md [拆镜与延镜]，
   本节不重复规定
5. **标注 `⚠配额溢出`** —— 以上都解决不了时，在台词后标注，留给人工

**禁止事项**
- 禁止为塞进配额而删信息、砍修饰、合并两句台词
- 禁止改变人物关系、剧情走向、情绪强度
- 禁止把长台词直接砍成短台词——要么等值压缩，要么延镜 / 拆镜

## 三、文化符号替换

**原则：保留剧情功能，替换文化外壳。**

| 源文化元素 | 处理方式 | 示例 |
|-----------|---------|------|
| 现实地点 / 机构 | 直译或换对等物 | 学校走廊 → `Riverside Academy Hallway` |
| 家族 / 宗族结构 | 换目标国对等的社会单位 | 宗祠议事 → 家族庄园图书室密谈 |
| 仪式 / 礼节 | 换目标国对等仪式 | 拜师礼 → 入学宣誓 |
| 信物 / 法器 | 功能保留、形态重设 | 青云令 → `Obsidian Sigil` |
| 专有名词 | 意译或意象化，不音译 | 灵气 → `Aether` |
| 货币 / 单位 | 换目标国通用单位 | 两银子 → 美元 / 比索 |

**必须保持不变的**
- 剧情走向、场次顺序、人物关系
- 每镜的画面内容（谁、在哪、做什么）
- 镜头边界与时长（唯一的例外是 [拆镜与延镜] 规定的延镜与拆镜，见 SKILL.md）

**特别提醒**
- 替换后要**全片自洽**：同一个概念不能这镜叫 `Aether`、那镜又叫 `Spirit Energy`
- 替换是**外观层**的，不要顺手把剧情也本地化了（中式校园霸凌 ≠ 美式校园霸凌，
  换成美式外壳但剧情照搬，不要改戏）
